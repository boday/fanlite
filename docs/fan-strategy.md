# 風扇調配建議

> 這不是醫療或硬體保固建議，而是依照 Apple Silicon 的熱設計與本機實測整理的
> 操作策略。若出現持續 100°C 以上、系統降頻、風扇異音或電池膨脹，請送修。

## 先釐清：高溫不是「所有零件一起高風險」

Mac 內有多個熱區，各自有不同上限：

| 元件 | 常見觀察 | 風險重點 |
|---|---|---|
| CPU / GPU hotspot（`Tp`、`Tg`） | 高負載 80–100°C 常見 | 過熱會降頻；長期極端高溫才增加老化風險 |
| SSD | 通常較低 | 控制器與 NAND 有獨立溫度限制 |
| 電池 | 通常 30–45°C | 高溫充電對電池老化影響最大 |
| 機身 / 掌心 | 越低越舒適 | 與 SoC 溫度不是等比例 |

所以「SoC 70°C」不等於「SSD、電池都在高風險」。真正該看的是**持續時間**、
**是否降頻**、**電池溫度**與**系統熱壓（thermal pressure）**，不是單一瞬間數字。

Apple Silicon 在低負載時風扇 0 RPM 是正常策略；但如果你希望更積極降溫，
可以把風扇維持在低中轉速，而不是長期全速。

## 本機建議曲線（FanLite 手動版）

目前 FanLite 是手動滑桿，尚未有自動曲線編輯器；以下是實務起點：

| 情境 | 建議 Fan 0 / Fan 1 | 說明 |
|---|---|---|
| 文書、瀏覽器、待機 | 1,200–1,800 RPM | 安靜；若溫度 < 60°C 可接受 |
| 一般開發、多分頁 | 2,500–3,200 RPM | 目前實測 3,000 RPM 可把 CPU 最高溫維持在約 60–73°C |
| 編譯、轉檔、影音 | 3,800–5,000 RPM | 以 `Tp` 最高溫 < 85°C 為目標 |
| 長時間滿載 / 超過 88–90°C | 5,200 RPM 到全速 | 優先壓住熱點；注意噪音與功耗 |
| 溫度 > 95°C 且持續 | 全速，並降低負載 | 若仍降頻，檢查散熱/環境溫度 |

**兩顆風扇建議同步。** 這台 16 吋 MacBook Pro 的兩顆風扇對應共享散熱模組；
同步通常比單顆狂轉更有效，也避免單側熱區。FanLite 的「同步兩顆風扇」預設關閉，
需要時請勾選；若只是診斷單顆風扇，才分開控制。

## 為什麼不建議長期全速

- 5,779 / 6,241 RPM 的邊際散熱收益遠低於噪音、功耗與軸承磨耗。
- 全速會把灰塵更快吸進散熱鰭片，長期反而降低散熱效率。
- 真正需要全速的是**持續高負載**，不是日常待機。
- 你接受較大聲音沒問題，但「全速」應該是保護策略，不是常態。

## 建議觀察指標

```bash
# 目前風扇與溫度
"$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" sensors --json

# 風扇模式與目標
"$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" fan status

# 系統熱壓
pmset -g therm
```

每天觀察：

1. 待機 CPU 最高溫是否長期 > 75°C。
2. 一般使用時是否經常 > 85°C。
3. 是否有 `thermal pressure`、降頻或風扇突然拉滿。
4. 電池溫度是否異常（接近 45°C 就不宜長時間充電）。

## FanLite v0.3.0 自動策略

勾選「80°C 自動增壓」後，FanLite 會在每次刷新時依 CPU 最高溫調整，並套用滯後：

- `< 80°C`：3,000 RPM
- `>= 80°C`：4,500 RPM
- `>= 88°C`：5,500 RPM
- `>= 90°C`：6,000 RPM（依各風扇硬體上限夾住）
- 回退：86°C 以下離開全速、84°C 以下離開高溫、76°C 以下回日常

這樣比手動滑桿更適合長時間觀察，也能避免在 79–81°C 邊界反覆升降。

## 目前實測

- 雙風扇 3,000 RPM：CPU 最高約 **60–73°C**，封裝功耗約 **8–25W**。
- `quiet` profile：約 **1,200 RPM**。
- `full` profile：**5,703 / 6,101 RPM**。
- 單風扇控制已驗證：
  - `fan set 2600 --fan 0` → Fan 0 約 2,600 RPM
  - `fan set 3400 --fan 1` → Fan 1 約 3,400 RPM

## 結論

以你的需求（接受聲音、優先降溫）：

- **日常先設 3,000 RPM，兩顆同步。**
- **高負載 4,500–5,000 RPM。**
- **持續 88°C 以上才拉到全速。**
- 不要讓兩顆長期全速；那是備援，不是常態。
- 若要更省心，下一版應加入「溫度曲線 + 5°C 滯後」自動控制，而不是靠手動滑桿。
