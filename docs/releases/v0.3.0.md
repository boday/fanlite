# FanLite v0.3.0 — 80°C 自動增壓

這個版本把「溫度超過 80°C 自動提高風扇」做成可驗證的政策，而不是只靠手動滑桿。

## 自動策略

| CPU 最高溫 | 兩顆風扇目標 |
|---|---|
| < 80°C | 3,000 RPM |
| >= 80°C | 4,500 RPM |
| >= 88°C | 5,500 RPM |
| >= 90°C | 6,000 RPM（Fan 0 會夾在 5,779） |

回退滯後：

- 全速降到 86°C 以下才退到 5,500
- 高溫降到 84°C 以下才退到 4,500
- 增壓降到 76°C 以下才回 3,000

這可以避免 79/81°C 之間反覆升降。

## 驗證證據

政策邊界測試：

```text
PASS 79.9°C normal: got 3000, expected 3000
PASS 80°C warm: got 4500, expected 4500
PASS 88°C hot: got 5500, expected 5500
PASS 90°C critical: got 6000, expected 6000
PASS critical exit 85.9: got 5500, expected 5500
PASS warm drops 75.9: got 3000, expected 3000
ALL POLICY TESTS PASS
```

真實負載測試（5 個 `yes` 程序，約 80 秒）：

```text
18:01:20 temp=81.7 fans=3000/2986 targets=3000/3000
18:01:25 temp=83.2 fans=3201/3009 targets=4500/3000
18:01:30 temp=77.7 fans=4498/4504 targets=4500/4500
...
18:02:38 temp=79.0 fans=2997/3019 targets=3000/3000
```

自動增壓在 81.7°C 觸發，兩顆風扇升到 4,500 RPM；降溫後回到 3,000 RPM。

## 安裝

下載 `FanLite-v0.3.0-macos-arm64.dmg`，拖到 Applications。

若尚未安裝 helper：

```bash
sudo "$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" daemon install
```

## 注意

- 自動增壓只在 FanLite 執行中生效。
- 關閉 App 前可按「自動」交還 macOS；目前不會在結束時強制改回 auto。
- 這是軟體溫控，不取代硬體散熱與環境溫度管理。
