## 維運注意：升級 App 必須 bootout／bootstrap

在 launchd job 仍 loaded 時用 `ditto` 直接替換 App bundle，會讓 job 快取的
cdhash 與新執行檔不符，出現 `state = not running` / `job state = spawn failed`。
`codesign -vvv --deep --strict` 會顯示 valid，binary 直接執行也正常，容易誤判。
正確升級順序：

```bash
launchctl bootout gui/$(id -u)/io.github.boday.fanlite
# 替換 ~/Applications/FanLite.app
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/io.github.boday.fanlite.plist
```

本次已實際遇到並以上述順序修復，詳情見 `audits/issue-1/round-3-ops.md`。

## 安裝

下載 `FanLite-v0.5.0-macos-arm64.dmg`，拖入 Applications。
若為既有使用者，請先 `launchctl bootout`，替換 App 後再 `launchctl bootstrap`（見上節）。

首次風扇控制仍需安裝 root helper：

```bash
sudo "$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" daemon install
```
