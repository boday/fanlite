# FanLite v0.4.0 — 登入自動啟動與溫控穩定化

這個版本回答「重開機後怎麼辦」，也修掉嚴格負載測試發現的風扇抖動。

## Added

### 登入時自動啟動

- 新增 per-user LaunchAgent：`~/Library/LaunchAgents/io.github.boday.fanlite.plist`
- 控制面板新增「登入時自動啟動 FanLite」勾選框
- 選單列新增「開機自動啟動」開關
- CLI：
  - `--enable-login-item`
  - `--disable-login-item`
  - `--login-item-status`
- 採 `RunAtLoad = true`、`KeepAlive = false`，登入後啟動一次；
  使用者手動結束後不會被強制拉回。

### 開機階段的風扇安全

- 本機已將 `/etc/smctl/config.toml` 的 `[fan] profile` 設為 `"auto"`：
  登入畫面前由 macOS 控制，避免一開機就全速。
- 若你的 `smctld` 曾被設成 `full`，請執行一次
  `smctl fan profile auto`；這是系統層的一次性設定。
- 使用者登入後，FanLite 在 2 秒內重新套用 FanLite 的溫控策略。

### 溫控取樣與穩定性

- 溫控判斷改為**獨立 2 秒輪詢**，UI 刷新仍維持 5/10/30/60 秒。
  這修正了 10 秒輪詢漏掉 80°C 短暫尖峰的問題。
- 降階加入 **45 秒最短停留（dwell）**。
- 增壓出場門檻由 76°C 降到 **70°C**：滿載時 4,500 RPM 的平衡溫度約
  74–80°C，原本的 76°C 會造成風扇每 6–12 秒反覆升降。
- 目前門檻：

| 進入 | 目標 | 降階條件 |
|---|---:|---|
| < 80°C | 3,000 RPM | — |
| >= 80°C | 4,500 RPM | < 70°C 且停留 45 秒 |
| >= 88°C | 5,500 RPM | < 82°C 且停留 45 秒 |
| >= 90°C | 6,000 RPM | < 85°C 且停留 45 秒 |

升階永遠立即生效，不受 dwell 限制。

### 3. 登入自動啟動

```text
$ launchctl print gui/501/io.github.boday.fanlite
state = running
pid = 60451
runs = 4
```

- 以 `launchctl bootstrap` 模擬登入：成功由 launchd 啟動（`ppid = 1`）。
- `launchctl kickstart -k`：`runs` 增加、PID 更新。
- 停用：plist 移除、`bootout` 後無 FanLite 行程。
- 重新啟用：`plutil -lint` 通過、再次 bootstrap 成功。

### 4. 開機階段設定

```text
$ grep -A2 '\[fan\]' /etc/smctl/config.toml
[fan]
profile = "auto"
```

`/Library/LaunchDaemons/one.leaper.smctl.daemon.plist` 具備
`RunAtLoad = true`、`KeepAlive = true`，smctld 會隨開機啟動。

## 安裝

下載 `FanLite-v0.4.0-macos-arm64.dmg`，拖到 Applications。

首次風扇控制：

```bash
sudo "$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" daemon install
```

啟用登入自動啟動：

```bash
"$HOME/Applications/FanLite.app/Contents/MacOS/FanLite" --enable-login-item
```

## 已知限制

- 登入自動啟動只在使用者登入後生效，FileVault 解鎖前沒有 FanLite 溫控。
- 尚未完成 Developer ID 簽章與公證，首次開啟可能需 Gatekeeper 手動放行。
- 尚未提供風扇曲線編輯器。
- 多使用者同時執行 FanLite 會搶 SMC，建議只讓一個使用者啟用。
