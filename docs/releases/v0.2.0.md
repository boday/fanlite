# FanLite v0.2.0 — 控制面板、雙風扇滑桿、DMG 安裝

首個具備完整互動介面的版本。

## Added

- **控制面板**：點選單列 →「開啟控制面板…」
- **Fan 0 / Fan 1 獨立滑桿**：可分別設定兩顆風扇 RPM
- **同步兩顆風扇**：勾選後拖動任一滑桿會同時設定兩顆
- **自動 / 日常 3000 / 安靜 / 全速** 快速按鈕
- **DMG 安裝映像**：拖曳 `FanLite.app` 到 `Applications`
- **App icon**：沿用風扇＋溫度計視覺
- 刷新頻率可直接在面板選擇 5 / 10 / 30 / 60 秒

## Verified

```text
Fan 0: actual 2998 RPM, target 3000 RPM
Fan 1: actual 3005 RPM, target 3000 RPM
```

單風扇控制：

```text
smctl fan set 2600 --fan 0  # Fan 0 -> 2600
smctl fan set 3400 --fan 1  # Fan 1 -> 3400
```

## 安裝

下載 `FanLite-v0.2.0-macos-arm64.dmg`，打開後把 App 拖到 Applications。

首次風扇控制：

```bash
sudo "$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" daemon install
```

## 已知限制

- 僅支援 Apple Silicon
- ad-hoc 簽章，尚未 Apple notarization
- 尚未提供風扇曲線自動編輯器
