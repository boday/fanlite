# FanLite v0.1.1 — 風扇控制與刷新修正

這個修補版處理 MVP 首次實機測試發現的兩個問題。

## Fixed

- **風扇控制無法切換**：release 產物現在同時包含 `smctl` 與 `smctld`，`daemon install` 可正常找到 helper。
- **刷新可能被延遲**：App 加入 `NSAppSleepDisabled`，避免背景 App Nap 把 10 秒刷新拉長。
- 本機設定重設為 10 秒；使用者在選單仍可選 5 / 10 / 30 / 60 秒。

## 驗證

```bash
"$HOME/Applications/FanLite.app/Contents/MacOS/FanLite" --once
"$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" fan status
```

實測風扇控制：

```text
Fan target set to 3000 RPM on all fans.
Fan 0: actual 3005 RPM, target 3000 RPM, mode manual
Fan 1: actual 2954 RPM, target 3000 RPM, mode manual
```

## 安裝

下載 `FanLite-v0.1.1-macos-arm64.zip`，解壓縮後放到 `~/Applications`。
首次開啟若被 Gatekeeper 阻擋，請到「系統設定 → 隱私權與安全性」按「仍要開啟」。
