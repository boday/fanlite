# FanLite v0.1.0 — 首個 MVP

首個可用的免費 macOS 選單列溫度／風扇工具。

## 亮點

- 選單列顯示 CPU 最高溫度、兩顆風扇 RPM、封裝功耗
- 刷新頻率可調：5 / 10 / 30 / 60 秒，預設 10 秒
- 風扇模式：`auto` / `quiet` / `full`（需安裝 smctl root helper）
- 僅讀取時不需要 root、不需背景服務
- 使用 MIT 授權、Apple 公證的 `smctl 0.2.4`
- 無網路、無遙測

## 安裝

下載 `FanLite-v0.1.0-macos-arm64.zip`，解壓縮後把 `FanLite.app`
放到 `~/Applications` 或 `/Applications`。

第一次開啟若被 Gatekeeper 阻擋，請到「系統設定 → 隱私權與安全性」
按「仍要開啟」。MVP 為 ad-hoc 簽章，尚未 Apple notarization。

## 驗證

```bash
"$HOME/Applications/FanLite.app/Contents/MacOS/FanLite" --once
```

範例輸出：

```text
cpu_max=68.3C fans=5730/6244RPM package=16.3W
```

## 風扇控制（選用）

```bash
sudo "$HOME/Applications/FanLite.app/Contents/Resources/bin/smctl" daemon install
```

安裝後可在 FanLite 選單切換風扇模式。未安裝時只有監看功能。
